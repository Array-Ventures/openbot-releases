# OpenBot for Array releases

Public desktop installers and update files for the Array AI Labs distribution of OpenBot.
The application source repository is maintained separately. This repository contains release
files and distribution notices; it is not the application source tree.

Downloads are public. Array account access requires an invitation. The product name remains
OpenBot, and the Array distribution uses a blue icon and separate application data.

## Platforms

- macOS: Apple silicon, signed and notarized DMG installer and ZIP update package.
- Linux: ARM64 AppImage. Native remote desktop streaming is not included in this target.
- iPhone: distributed separately through the Array internal TestFlight group.

Intel Mac and Linux x64 installers are not included in the current Array releases.

## Updates

Use the latest published release for a manual installation. Existing Array 0.51.1 installations
have automatic updates disabled and need one manual installation of an updater-enabled release.
Later compatible desktop builds can check this repository for updates.

Release notes identify the source revision, supported targets, and known limitations. Checksum
files accompany the installers. Keep the license and corresponding-source materials with the
release. The licenses included with each component apply to that component.

Builds run locally. GitHub Actions is disabled in this repository.
